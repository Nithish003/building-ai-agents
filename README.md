# 🤖 Building AI Agents — Learning Resources

A curated roadmap for learning how to build LLM-powered AI agents, moving from
fundamentals → hands-on code → production best practices → deep reading.

> Maintained by [@Nithish003](https://github.com/Nithish003). Contributions / new links welcome — just add them to the relevant section.

**Suggested path:** Start with the Anthropic "Building Effective Agents" video + guide → build with Microsoft's beginner repo → then do one agent-from-scratch project.
